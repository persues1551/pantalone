# checklist.md — 报告生成自检清单（降级版 v2.0）

**注意**：本文件已从"Subagent防假规则"降级为"报告生成自检清单"。
不存在独立的Subagent调用，所有分析由单一LLM完成。

## 报告自检清单（每次生成报告前必须检查）

### 数据完整性
- [ ] 指数数据是否来自缓存/API（非编造）？
- [ ] 涨跌停数据是否区分板块阈值（主板10%/科创创业20%/北交30%）？
- [ ] 成交额是否有变化率对比（vs前N日均值）？
- [ ] 技术指标（RSI/MACD/MA）是否从indicators JSON读取？

### 模拟盘
- [ ] 是否调用了 `amadeus_sim_integrate.py status`？
- [ ] 持仓浮盈浮亏是否使用实时价格（非买入价）？
- [ ] 是否仅只读查询模拟盘；如需 `daily_update`，是否已获得该动作的逐次明确授权？
- [ ] 评分是否仅作研究证据，未直接生成买入、仓位或分批计划？
- [ ] 是否完整通过 `rules/risk_rules.md` 的8项建仓资格门槛？
- [ ] 同一股票全部名义仓位合计是否≤25%，且最小一手未突破上限？
- [ ] 候选仓位是否按当次风险预算计算，而非按评分档位或大盘状态套用固定比例？
- [ ] 每一批模拟盘写入是否有价格、数量、失效条件和该动作的逐次明确授权？

### 风控
- [ ] 股票止损是否唯一采用 `rules/pool_rules.md` 的 A+/A/B/C 权威池规则？
- [ ] 股票止盈是否唯一采用 `rules/risk_rules.md` 的 +12%/+20%/+30% 阶梯？
- [ ] 均线和持仓天数是否仅作为复核证据，未被写成独立减仓或清仓触发器？
- [ ] RSI、量价、高开、消息、资金和大盘状态是否只作证据或阻断项，未反向推导交易动作？
- [ ] 风险排雷和合规审查是否完成，Critical/Major未关闭时是否阻断候选？

### 报告格式
- [ ] 是否包含模拟盘部分？
- [ ] 是否标注数据来源？
- [ ] 是否包含风险声明？
- [ ] 是否去除了Subagent分工标签？

### 排雷
- [ ] 新买入标的是否通过排雷扫描？
- [ ] 数据缺失项是否标注？
