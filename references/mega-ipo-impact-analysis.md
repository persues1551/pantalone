# 巨型IPO冲击分析框架

> 适用场景：主人问"XX IPO对科技股/市场的影响"、"XX上市前是否该清仓"、"能否类比中芯国际上市"等
> 触发词：IPO、上市、抽血、利好出尽、打新、申购、科创板IPO
> `as_of: 2026-07-13`。历史案例和当前IPO数据均需在使用时重新核验来源；本文不自动触发清仓、交易或观察池写入。

## 核心逻辑

巨型半导体/科技IPO对市场的冲击通常涉及三重效应：

```
  ① 抽血效应 — IPO冻结/募资金额吸走市场流动性
  ② 利好出尽 — 上市预期已提前消化，上市=兑现
  ③ 比价效应 — 首发估值拉低行业估值中枢
```

三重效应同时叠加 → **系统性板块回调风险**

## 三、类比分析框架

当用户问"XX IPO能否类比中芯国际"时，按以下维度逐项对比：

| 维度 | 问题 | 影响方向 |
|------|------|---------|
| **IPO规模** | 募资金额（越小抽血效应越弱） | 中芯532亿 > 长鑫295亿 |
| **科技股位置** | 上市前科技股在"山顶"还是"半山腰"？ | 越高越危险 |
| **市场所处阶段** | 牛市/震荡/熊市？ | 牛市下跌快但恢复也快 |
| **板块资金状态** | 已提前流出还是仍在流入？ | 已流出=部分风险释放 |
| **上市形式** | 先H后A / 纯A / 分拆？ | 先H后A多一层预期差 |
| **同比IPO数量** | 同期还有其他大IPO吗？ | 叠加=更大冲击 |
| **打新冻结** | 申购冻结资金量级？ | 约≈募资额×回拨比例 |

### 判断流程

```
Step 1: 按上表逐维对比，标注"相似""不同"
Step 2: 区分"可类比"和"不可类比"的维度
Step 3: 如果"科技股位置"和"板块资金状态"不同 → 历史不会简单重复
Step 4: 结合持仓核对权威风险合同并形成待授权方案：
  - 持有科技股 → 标注IPO暴露与25%单票上限，不由事件类比直接生成交易动作
  - 持有ETF → 按ETF独立风险规则核对流动性、折溢价和类型止损
  - 持有非科技股 → 仅核对A+/A/B/C权威池止损与+12%/+20%/+30%止盈
  - 任何生产动作 → 证据充分后形成待授权方案，等待用户逐次明确授权
Step 5: 标注置信度（通常0.60-0.75，历史类比有局限性）
```

## 四、公开数据获取方案

当搜索被CAPTCHA拦截时，以下方案已验证可靠：

### 方案A：东方财富新闻搜索（推荐）
```
URL: https://so.eastmoney.com/news/s?keyword=<关键词>
工具: Playwright browser
步骤：
  1. 用 playwright navigate 到搜索结果页
  2. 用 evaluate 从新闻列表提取标题+摘要+链接
  3. 打开需要的文章链接，提取正文 (CSS selector: #ContentBody)
```

### 方案B：腾讯API实时行情
```
URL: https://qt.gtimg.cn/q=<股票代码>
格式: GBK编码，需 iconv 转换
字段: ~分割的字符串，第3字段=现价，第32字段=涨跌幅%
```

### 方案C：东方财富API板块资金流
```
URL: https://push2.eastmoney.com/api/qt/clist/get?cb=&pn=1&pz=30&po=1&np=1&ut=bd1d9ddb04089700cf9c27f6f7426281&fltt=2&fid=f3&fs=m:90+t:2&fields=f2,f3,f4,f12,f14,f62
用途: 获取申万行业涨幅+净流入数据
```

### 方案D：缓存数据
```
路径: $HERMES_HOME/cache/amadeus/market_YYYY-MM-DD.json
     $HERMES_HOME/cache/amadeus/emotion_YYYY-MM-DD.json
用途: 获取历史收盘数据（板块涨跌/资金流/宽度）
```

## 五、常见陷阱

1. **盲从中芯类比**：每次IPO的市场环境不同，"科技股位置"是最关键的差异变量
2. **忽略提前调整**：如果科技股已在IPO前暴跌（如2026年7/10半导体-5.28%），部分风险已释放，不需要重复计算
3. **把ETF当个股**：ETF成分分散，IPO冲击对ETF的影响远小于对单一个股
4. **忘记打新抽血**：除了IPO募资，打新冻结资金量对流动性的短期冲击可能更大
5. **过度反应**：巨型IPO短期冲击明显，但中长期看完善产业链，调整后往往是布局机会
