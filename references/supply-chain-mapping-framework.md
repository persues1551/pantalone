# 供应链拆解框架 — Supply Chain Mapping

## 核心理念

Serenity式供应链分析：从终端需求出发，逐层拆解产业链，找到每一层对应的A股受益标的。

## 供应链分析5步法

### Step 1：确定终端需求
- 当前版本/补丁驱动了什么终端需求？
- 示例：AI算力基建 → 需要大量GPU服务器
- 示例：新能源汽车 → 需要电池、电机、电控

### Step 2：逐层拆解供应链

```
终端需求 → 系统集成 → 核心部件 → 基础材料
                         ↓
                    制造设备 → 耗材备件
```

**模板格式**：
```
┌─ 终端: 电动汽车
├─ L1 系统: 电池包(宁德时代) | 电驱系统(汇川技术) | 热管理(三花智控)
├─ L2 部件: 正极材料(容百科技) | 负极材料(贝特瑞) | 电解液(天赐材料) | 隔膜(恩捷股份)
├─ L3 材料: 碳酸锂(赣锋锂业) | 镍/钴(华友钴业) | 铜箔(嘉元科技)
├─ L4 设备: 锂电设备(先导智能) | 涂布机(赢合科技)
└─ L5 耗材: 石墨电极(方大炭素)
```

### Step 3：标注利益传导机制

哪个环节最受益？判断标准：
1. **供给壁垒**: 产能扩张难度越大→越受益（如光刻胶）
2. **需求弹性**: 该环节成本占比小但不可或缺→越受益（如芯片IP）
3. **竞争格局**: CR3越高→越受益（如DRAM）
4. **国产替代空间**: 当前国产率越低→弹性越大

| 环节 | 受益程度 | 原因 |
|------|---------|------|
| 光模块 | ★★★★★ | 算力必配+国产主导 |
| AI芯片 | ★★★★☆ | 壁垒极高但国产份额低 |
| 服务器代工 | ★★★☆☆ | 有壁垒但毛利低 |
| PCB | ★★★☆☆ | 需求大但竞争激烈 |

### Step 4：标记A股/港股对应标的

```
光模块:
  [A] 中际旭创(300308) ★龙一 — 全球光模块第一
  [A] 新易盛(300502)  ★龙二 — 800G量产
  [A] 光库科技(300620) — 光芯片/器件
  ⚠ 300xxx=创业板，主人不能直接买个股

替代方案:
  [A] 通信ETF(515880) — 含光模块权重
```

### Step 5：输出格式

```
📋 供应链拆解: {终端需求名称}

终端驱动: {版本/补丁名称} — 一句话说明为什么这个需求在增长

L1 系统集成:
  {公司名}({代码}) — {角色} — {受益逻辑}

L2 核心部件:
  {公司名}({代码}) — {角色} — {受益逻辑}

L3 基础材料:
  {公司名}({代码}) — {角色} — {受益逻辑}

🏆 最受益环节: {环节名称}
  理由: {供给壁垒/需求弹性/竞争格局/国产替代}

⚠️ 创业板/科创板个股需ETF替代:
  {替代方案}
```
