# 补丁事件跟踪系统 — Patch Event Tracker

## 核心理念

补丁（Patch）是指临时性但能短期内影响股价的事件。与版本不同，补丁持续时间短（1天-2周）、影响范围窄（个股或细分板块）。补丁可以强化版本（补丁确认版本逻辑）或独立存在（个股独立行情）。

## 补丁分类

| 类型 | 影响时间 | 影响范围 | 示例 |
|------|---------|---------|------|
| 财报预喜/预亏 | 1-3天 | 个股+行业 | 万华中报+60% |
| 重大合同/订单 | 1-2天 | 个股 | 中标50亿大单 |
| 产品发布/获批 | 1-5天 | 个股+细分 | 新药获批、新芯片发布 |
| 股东增持/减持 | 1-2天 | 个股 | 大股东增持5% |
| 政策发布 | 1-5天 | 行业 | 产业补贴政策 |
| 突发利空 | 1-3天 | 个股/行业 | 董事长被查、产品召回 |

## 补丁检查清单（集成到每日扫描）

### 日常扫描项

```
□ 今日有哪些股票发布中报/季报预告？
□ 涨幅>7%的股票是否有公告驱动？
□ 跌幅>5%的股票是否有利空公告？
□ 今日有哪些重大政策/行业新闻发布？
□ 观察池标的有无财报/事件驱动？
```

### 财报日历（自动跟踪）

1. 从东方财富/AKShare获取当日财报预告列表
2. 筛选观察池中当天/近3天出财报的标的
3. 预告发布后自动评估"预喜/预平/预亏"

### 集成方式

- **早间速报**: 列出当日重要财报/事件
- **收盘复盘**: 评估当日补丁对股价的实际影响
- **版本系统**: 补丁验证版本（如化工中报批量预喜 → 验证化工周期版本）

## 补丁→版本验证机制

| 补丁类型 | 验证效果 | 对版本的影响 |
|---------|---------|-------------|
| 板块内多公司财报预喜 | 确认产业逻辑 | 版本置信度上升 |
| 板块内龙头业绩不及预期 | 质疑产业逻辑 | 版本可能退潮 |
| 重大政策利好 | 新版本催化剂 | 可能启动新版本 |
| 个股独立利好 | 不涉及版本 | 个股行情 |
