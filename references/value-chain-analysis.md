# 价值传导分析 — Value Chain Analysis

## 核心理念

产业链上的利润不是平均分配的，**特定环节会在特定阶段捕获最大利润**。
价值传导分析的目标：找到当前版本下利润增量最大的环节。

## 分析框架

### 四维评估

| 维度 | 权重 | 问题 | 数据源 |
|------|------|------|--------|
| **供需缺口** | 30% | 这个环节扩产容易吗？ | 产能利用率、capex计划 |
| **议价能力** | 30% | 对上下游谁有话语权？ | 毛利率变化、付款周期 |
| **国产替代** | 25% | 国产化率当前多少？提升空间？ | 行业研报、政策目标 |
| **政策倾斜** | 15% | 政策支持力度？ | 政策文件、补贴数据 |

### 典型传导路径

```
需求爆发 → 最先受益的是最稀缺的环节
         → 然后是瓶颈环节（产能不足的）
         → 最后才是同质化环节（充分竞争的）

示例 - AI算力:
  1. 最先: GPU芯片（供给绝对稀缺）→ 寒武纪/海光信息
  2. 其次: 光模块（800G供不应求）→ 中际旭创
  3. 再后: 服务器（有壁垒但毛利低）→ 工业富联
  4. 最后: PCB/散热（竞争充分）→ 沪电股份
```

### 环节标记

| 环节类型 | 标记 | 操作策略 |
|---------|------|---------|
| 稀缺环节 | 🔴 最大受益 | 重点配置，容错率高 |
| 瓶颈环节 | 🟡 次优 | 可配置，需跟踪产能 |
| 跟随环节 | 🟢 一般 | 谨慎配置，小仓位 |
| 同质化环节 | ⚪ 边缘 | 不参与，除非估值极低 |
