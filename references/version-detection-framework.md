# 版本识别系统 — Version Detection Framework

## 核心理念

A股投资的核心是**识别当前市场的主线版本**。版本是持续数周至数月的投资主线，决定了资金流向和赚钱效应所在。

## 版本的定义

一个"版本"必须同时满足以下条件：

### 判定标准（全部满足才算版本确认）

| 条件 | 量化指标 | 说明 |
|------|---------|------|
| **板块强度** | 板块指数近20日涨幅 > 5% | 跑赢大盘 |
| **资金持续流入** | 近5日板块资金净流入 > 50亿 | 不是一日游 |
| **成交额占比** | 板块成交额/全市场 > 5%且连续3日上升 | 资金在集中 |
| **板块宽度** | 板块内上涨家数占比 > 60% | 不是少数权重股拉抬 |
| **催化明确** | 有可验证的产业/政策/业绩催化 | 不是纯情绪炒作 |
| **持续性** | 催化预计持续 > 4周 | 不是短期事件 |

### 版本生命周期

```
潜伏期 → 确认期 → 加速期 → 高潮期 → 退潮期
  ↑          ↑         ↑         ↑         ↑
  无人关注   开始有板  全民热议  板块成交  涨幅回吐
  块涨停             占比见顶  50%以上
```

| 阶段 | 识别特征 | 操作策略 | 风险 |
|------|---------|---------|------|
| **潜伏期** | 板块跑赢大盘但无人讨论 | 标注早期版本证据；不得据此建立底仓 | 可能夭折 |
| **确认期** | 板块涨停>3只+资金连续流入>3天 | 复核建仓证据；动作通过 `rules/risk_rules.md` 完整门槛 | 已错过最低点 |
| **高潮期** | 全民热议+成交额占比>15%+龙一加速 | 核对权威止盈状态；不生成新买入方案 | 随时见顶 |
| **退潮期** | 资金连续流出+涨停数归零+板块跌幅>5% | 核对权威池止损状态；退池或退出仅允许逐动作授权路径 | 反弹是出货 |

### 退出条件（版本结束的信号）

- 板块指数跌破MA20
- 资金连续3日净流出
- 成交额占比回落到5%以下
- 龙头股出现跌停/连续大跌
- 新的替代版本出现

## 版本分类

| 类型 | 持续时间 | 来源 | 示例 |
|------|---------|------|------|
| **宏观版本** | 3-12个月 | 利率/汇率/政策周期 | 红利低波、中特估 |
| **产业版本** | 1-6个月 | 技术迭代/供需拐点 | AI算力、新能源出海 |
| **事件版本** | 1-4周 | 突发事件/政策催化 | 国企改革、地缘冲突 |
| **季节版本** | 按日历 | 财报季/节假日 | 中报行情、春节消费 |

## 当前版本的判定流程

### 每日检查（集成到收盘复盘/晚间复盘）

```
1. 扫描近20日涨幅TOP10板块
2. 对候选板块逐项检查6个判定条件
3. 输出当前处于哪个版本、哪个阶段
4. 如果无版本确认 → 输出"无明确主线，以防御为主"
5. 如果有变化（新版本/阶段转换） → 预警
```

### 版本状态输出格式

```
📌 当前版本: AI算力基建
   阶段: 加速期（第5周）
   确认依据: 板块20日+12.3% | 资金连续7日净流入 | 成交额占比11.2%
   催化: 英伟达财报超预期+国内AI服务器集采
   龙头: 中际旭创(300308) | 工业富联(601138) | 源杰科技(688498)
   证据摘要: 版本处于加速期；不得据此直接持有、止盈或改变仓位

📌 候选版本: 化工周期
   阶段: 潜伏期（第1周）
   信号: 万华化学中报预增60-70% | 行业利润断层 | 板块20日+2.1%
   尚未确认: 板块宽度<60% | 成交额占比仅3.2%
   观察条件: 若连续3日资金流入则升级确认
```

## 版本与Pantalone的集成

1. **收盘复盘** → 输出当前版本状态
2. **晚间复盘** → 判断版本阶段变化
3. **周报** → 版本回顾与展望
4. **OCIFQ选股** → 优先从当前版本板块中选股
5. **观察池管理** → 版本龙头仅进入候选清单；入池写入必须通过 `rules/pool_rules.md` 并获得用户逐次明确授权

## 实现脚本

当前候选不携带版本检测执行脚本；按本文框架手工判断并标注数据来源。外部实现只有在`$HERMES_HOME`下真实存在、通过字段与单位验证后才可接入。

输入：板块行情数据、资金流、连板数据
输出：当前版本判定、阶段、置信度
