# 统一深度个股研究工作流

> 版本：v1.2（2026-06-22）
> 整合：OCIFQ五维评分证据 + 财务三爆 + 蒙特卡洛 + 主力检测 + 多空辩论 + 权威退出合同 + 左右侧技术证据 + 完整资格门槛后的待授权方案

## 触发条件

| 指令 | 执行范围 |
|------|----------|
| "深入研究XX"、"分析XX"、"XX怎么样" | 完整8阶段流水线 |
| "研究建仓XX"、"建仓建议" | 8阶段 + 建仓建议模块 |
| "批量分析XX XX XX" | 每只独立8阶段，数据采集批量执行 |
| "主力行为XX"、"筹码分析" | 仅Stage 2 |
| "快速诊断XX" | 仅Stage 1+2+8（跳过辩论和策略） |

## 8阶段流水线总览

```
Stage 1: 数据采集（并行3子任务）
   ├─ 技术面+风险：K线/MA/MACD/RSI/KDJ/BOLL/VaR/CVaR/蒙特卡洛
   ├─ 新闻+基本面：研报/公告/催化剂/估值/分红送转
   └─ 情绪+资金面：融资融券/北向/龙虎榜/板块资金流/情绪温度
          ↓
Stage 2: 主力行为检测（Python脚本，独立Stage不可合并）
   └─ OBV/量价/筹码/换手率/资金流 → 5维度评分(0-100)
          ↓
Stage 3: OCIFQ五维评估（delegate_task）
   ├─ O: 寡头定价权（CR3/壁垒/提价能力/毛利率稳定性）
   ├─ C: 长周期催化（持续≥4季度的产业逻辑）
   ├─ I: 行业利润断层（同行≥3家同步改善/上下游联动）
   ├─ F: 财务三爆（营收≥30%/利润≥50%/毛利率≥5pct）← 必须含季度数据表
   └─ Q: 连续季报验证（4季度趋势/加速/平稳/恶化）
          ↓
Stage 4: 多空辩论（delegate_task并行）
   ├─ 🐂 多头分析师：上行逻辑+目标价+触发概率+支撑证据
   ├─ 🐻 空头分析师：下行风险+止损位+触发概率+风险证据
   └─ 加权预期收益 = 多头概率×上行空间 + 空头概率×下行空间
          ↓
Stage 5: 风控评估（delegate_task）
   ├─ 风险量化：VaR/CVaR/最大回撤/压力测试/蒙特卡洛
   ├─ 排雷扫描：ST/质押/商誉/审计/现金流（9项）
   └─ 筹码风险：股东户数/限售解禁/大宗交易
          ↓
Stage 6: 合规审查（delegate_task）
   └─ 涨跌停/停牌/限售解禁/板块限制/异常波动公告
          ↓
Stage 7: 待授权策略（综合Stage 1-6）
   ├─ 建仓证据：回调/突破/事件驱动只作复核证据
   ├─ 技术证据：左侧（均线+低PE+高股息）/ 右侧（放量突破）不得单独触发动作
   ├─ 风险暴露：单票全部仓位合计不得超过25%，最小一手不是例外
   ├─ 止损止盈：A+/A/B/C权威池止损 + 12%/20%/30%分批止盈
   └─ 风险收益比：≥2:1只是完整建仓门槛之一；通过全部门槛后仅形成待授权建议
          ↓
Stage 8: Pantalone决策（最终汇总）
   └─ 证据、字段和风险完整的深度研究报告，不以行数衡量质量
```

## ⚠️ 报告输出铁律

**深度研究报告必须直接输出完整版，不压缩、不摘要、不拆分询问。**

用户原话："直接输出完整的，以后也是"。

### 报告完整性要求

| 章节 | 最低要求 | 错误做法 |
|------|----------|----------|
| OCIFQ五维评估 | 每维度200-300字详细分析 + 财务三爆表(4-8季度) + 行业断层对比表 + 降级规则检查 | 只给评分表格 ❌ |
| 多空辩论 | 多头3逻辑+催化+目标价+概率+证据 / 空头3风险+利空+下行目标+概率+证据 + 加权收益计算 | 压缩为一行结论 ❌ |
| 风险评估 | VaR/CVaR解读+最大回撤+波动率+压力测试+蒙特卡洛+排雷9项+止损方案 | 只给风险评级 ❌ |
| 交易策略 | 建仓证据+左侧/右侧证据+25%风险上限+权威退出合同+风险收益比+待授权方案 | 只给一句话建议 ❌ |
| Pantalone决策 | 角色共识表(详细版)+技术面摘要+操作方案+假设与失效条件+核心矛盾分析 | 只给BUY/SELL/HOLD ❌ |

### 正确的报告结构

```
1. 最终结论（决策矩阵，含OCIFQ/主力/风控/策略一览）
2. OCIFQ五维评估（完整版）
   - 五项评分汇总表
   - 财务三爆表（最近4-8季度，含YoY/QoQ/毛利率Δ/三爆判断）
   - 三爆硬指标逐项判断
   - 行业利润断层对比表（≥3家同行）
   - 每维度详细分析（200-300字，含数据支撑）
   - 降级规则检查
3. 主力行为分析（5维度信号详解）
4. 多空辩论（完整版）
   - 宏观与行业背景
   - 多头视角（核心逻辑+催化因素+目标价体系+支撑证据）
   - 空头视角（核心风险+利空因素+下行目标价+风险证据）
   - 加权预期收益计算（情景概率矩阵）
5. 角色共识分析（7角色详细版，含核心发现）
6. 技术面详细分析（均线系统+指标矩阵+量价特征+蒙特卡洛）
7. 风险评估详细分析（VaR/CVaR+最大回撤+波动率+压力测试+排雷9项+止损方案）
8. 待授权方案（建仓证据+25%风险上限+权威退出合同+风险收益比+授权状态）
9. 关键假设与失效条件
10. 核心矛盾分析（多空博弈分歧点+关键变量+Pantalone综合判断）
11. 风险提示与纪律铁则
```

## Stage详细规范

### Stage 1: 数据采集（并行）

用 `delegate_task` 并行启动3个子任务：

**子任务A：技术面+风险**
MA5/10/20/60/120/250、MACD(12,26,9)、RSI(14)、KDJ(9,3,3)、BOLL(20,2)、VaR(95%)、CVaR(95%)、最大回撤、蒙特卡洛(10000次)、Beta、波动率(20d/60d)、左侧机会判定、右侧突破判定

**子任务B：新闻+基本面**
近期新闻/研报、财务三爆数据、PE/PB/PEG、ROE/毛利率/净利率、分红送转、行业对比

**子任务C：情绪+资金面**
融资融券余额、北向资金持仓、龙虎榜、板块资金流、情绪温度

### Stage 2: 主力行为检测（独立，不可合并）

该外部能力为`optional`。`capability probe`：确认`HERMES_HOME`非空，且脚本是存在的普通文件。`fallback`：缺失或执行失败时，按`references/main-force-detection.md`手工计算可获得的维度；缺失维度保持unknown，不生成综合主力评分，也不得声称脚本已运行。

```bash
python3 $HERMES_HOME/scripts/amadeus/main_force_detector.py <code>
```

仅在脚本成功且五个维度数据完整时输出综合评分；否则输出已验证信号、缺失项和降级说明。
详见 `references/main-force-detection.md`

### Stage 3: OCIFQ五维评估

用 `delegate_task` 执行。**必须包含**：
- 每维度200-300字详细分析（含数据支撑）
- 财务三爆表（最近4-8季度）
- 行业利润断层对比表（≥3家同行）
- 降级规则检查
- web搜索同行业公司业绩数据

### Stage 4: 多空辩论（delegate_task并行）

**不可跳过。** 并行启动2个子任务：
- 多头分析师：核心逻辑+催化因素+目标价(短/中/长)+触发概率+支撑证据
- 空头分析师：核心风险+利空因素+下行目标+触发概率+风险证据
- 加权预期收益 = 多头概率×上行空间 + 空头概率×下行空间

### Stage 5: 风控评估

VaR/CVaR解读、最大回撤分析、波动率评估、压力测试、蒙特卡洛模拟(30日)、排雷9项检查、止损建议

### Stage 6: 合规审查

涨跌停检查、停牌风险、限售解禁、板块限制、异常波动公告、监管关注、合规建议

### Stage 7: 待授权策略

建仓证据(回调/突破/事件驱动复核)、左侧右侧证据判定、25%单票总暴露上限、动态风险预算、A+/A/B/C权威池止损、+12%/+20%/+30%分批止盈、风险收益比计算、授权状态

### Stage 8: Pantalone决策

综合全部产出，按字段、证据、风险、失效条件和数据缺口验收报告完整度。保留各Stage影响结论的证据链，不机械复制内容，不以行数衡量质量。

## 与Pantalone其他模块的关系

| 模块 | 关系 |
|------|------|
| OCIFQ选股 | Stage 3直接使用OCIFQ框架 |
| 蒙特卡洛 | Stage 1计算，Stage 5压力测试使用 |
| 财务三爆 | Stage 3的F维度核心指标 |
| 主力检测 | Stage 2独立执行，结果注入后续Stage |
| 多空辩论 | Stage 4必经，使用加权预期收益模板 |
| 权威退出合同 | Stage 7止损止盈策略；均线和持仓天数仅作复核证据 |

| 观察池 | 研究完成后可建议入池/退池 |
| 预测验证 | 默认只生成待写入建议；仅在用户明确授权后写入decision_log，后续复盘验证 |
